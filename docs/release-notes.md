# Release Notes

## v1.0.0 - September 2026

The first stable release of GitHub Green Test, a learning repository for
understanding GitHub's contribution graph mechanics.

### Features
- Comprehensive documentation covering contribution rules, setup, and best practices
- Example scripts for creating dated commits, analyzing patterns, and generating reports
- Utility scripts for validation, email checking, setup, and data export
- Test suite covering dates, emails, setup, hooks, validation, and export
- Pre-commit hook example for email validation
- Terminal-based contribution calendar renderer

### Documentation
- README with project overview, usage, and full documentation index
- Detailed FAQ covering common questions
- Troubleshooting guide for resolving contribution graph issues
- Architecture overview with design decisions
- Commit message conventions guide
- CONTRIBUTING guide for new contributors
- CHANGELOG tracking all project changes

### Tools
- `commit_analyzer.py` - Analyze commit patterns and statistics
- `weekly_report.py` - Generate weekly activity reports
- `natural_distribution.py` - Plan realistic commit schedules
- `contribution_calendar.py` - Render contribution graphs in terminal
- `validate_commits.sh` - Verify commit authorship and dates
- `check_email.sh` - Validate email configuration
- `export_history.sh` - Export commit history to CSV
- `daily_summary.sh` - Show today's activity summary
