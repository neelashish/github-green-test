# 12-Factor App

1. Codebase - one repo many deploys
2. Dependencies - declare explicitly
3. Config - env vars
4. Backing services - attached resources
5. Build/Release/Run - separate stages
6. Processes - stateless
7. Port binding
8. Concurrency - scale via processes
9. Disposability - fast start graceful stop
10. Dev/prod parity
11. Logs as event streams
12. Admin as one-off processes
